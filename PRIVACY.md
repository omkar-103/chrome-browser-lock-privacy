# Privacy Policy — Chrome Browser Lock

**Last updated:** September 5, 2026

**Created by:** Omkar Parelkar

Chrome Browser Lock is an independent Chrome extension designed to protect a user's browser session with password or PIN authentication.

This Privacy Policy explains what information Chrome Browser Lock handles, why it is needed, how it is used, and how it is protected.

---

## 1. Privacy at a Glance

Chrome Browser Lock is designed with a local-first privacy approach.

- Your authentication credentials are handled locally on your device.
- Authentication credentials are not stored as plain-text credentials.
- Information needed for session restoration is stored locally.
- The extension does not require an account.
- The extension does not operate a Chrome Browser Lock cloud service.
- The extension does not use advertising trackers, analytics, or telemetry.
- The extension does not sell user information.
- The extension does not intentionally share user information with third parties.
- The extension does not intentionally transmit your authentication credentials or protected session information to external services.

---

## 2. Information the Extension Handles

Chrome Browser Lock handles limited information that is necessary to provide its security features.

### Authentication Information

The extension handles authentication information that you provide when configuring or using the extension, including:

- Password credentials
- PIN credentials
- Recovery key information

These credentials are processed locally and are not stored as readable plain-text credentials.

### Session Information

When session protection and restoration are used, the extension may temporarily handle information about the currently open browser session.

This can include:

- Open tab URLs
- Tab titles
- Pinned-tab status
- Information about browser windows needed to restore the session

This information is used for protecting and restoring the browser session.

The extension does not need to store the contents of the webpages represented by these tabs.

### Settings

The extension stores settings required to provide features selected by you, which may include:

- Authentication preferences
- Lock-on-startup settings
- Automatic lock settings
- New-tab and new-window protection settings
- Incognito protection settings
- Session restoration preferences
- Appearance preferences
- Other extension configuration settings

### Security Activity

The extension may maintain a local security activity log containing events such as:

- Browser locked
- Browser unlocked
- Failed authentication attempt
- Recovery activity
- Security-related settings changes

The security activity log is intended to record security events rather than the content of your browsing activity.

---

## 3. Information the Extension Does Not Intentionally Collect

Chrome Browser Lock does not intentionally collect or store:

- Webpage content
- Cookies
- Form contents
- Search queries
- Page text
- Keystrokes entered into websites
- Personal communications
- Payment information
- Location information
- Advertising profiles
- Chrome browsing-history records

The extension may handle URLs of currently open tabs when required for session protection and restoration. These URLs are used for that functionality and are not used to create an advertising or browsing-history profile.

---

## 4. How Your Authentication Information Is Protected

Chrome Browser Lock is designed so that passwords, PINs, and recovery credentials are not stored as readable plain-text credentials.

Authentication information is processed using cryptographic protection mechanisms before verification data is stored locally.

The original authentication credentials are not intentionally persisted as readable credentials in the extension's local storage.

---

## 5. Recovery Key

Chrome Browser Lock provides a recovery-key mechanism to help users regain access if they forget their configured authentication credentials.

The recovery key:

- Is provided to the user during setup
- Can be copied or saved by the user
- Is not intentionally stored as a readable recovery key by the extension
- Is processed locally when used for recovery
- Is not intentionally transmitted to an external service

Recovery information used during the recovery process is temporary and limited to the recovery operation.

Users are responsible for keeping their recovery key secure. Anyone who obtains the recovery key may be able to use it to reset the extension's authentication credentials.

---

## 6. Session Snapshots and Tab Information

When the browser session is protected, Chrome Browser Lock may create a temporary local session snapshot so that the protected session can be restored after successful authentication.

The session snapshot may contain information such as:

- Tab URLs
- Tab titles
- Pinned-tab status
- Browser window information required for restoration

This information is:

- Stored locally on the user's device
- Used for session protection and restoration
- Not intentionally transmitted to external services
- Removed according to the extension's session-management behavior after the protected session is restored

The extension does not use session snapshots for advertising, analytics, or user profiling.

---

## 7. Local Data Storage

Chrome Browser Lock uses Chrome's local extension storage for information required to operate its security and session-protection features.

Locally stored information may include:

- Authentication verification information
- Security state
- User preferences
- Session information
- Security activity information
- Temporary recovery information

The extension does not provide its own cloud account or cloud storage service for this information.

---

## 8. Network Requests and External Services

Chrome Browser Lock does not require an external backend or account to provide its core functionality.

The extension does not intentionally send the following information to a Chrome Browser Lock server:

- Passwords
- PINs
- Recovery keys
- Session information
- Tab URLs
- Security activity logs
- User settings

The extension does not use advertising networks, analytics services, or telemetry services.

---

## 9. Chrome Permissions

Chrome Browser Lock requests Chrome permissions that are necessary for its implemented functionality.

### `storage`

Used to store information required for authentication, security state, settings, activity information, and session protection locally.

### `tabs`

Used to access information about open tabs required for protecting and restoring the browser session and managing protected tabs.

### `windows`

Used to access browser-window information required for session protection and restoration.

### `alarms`

Used to support automatic locking and scheduled security operations.

### `idle`

Used to detect system inactivity when automatic locking based on inactivity is enabled.

Chrome Browser Lock does not request:

- `history`
- `cookies`
- `webRequest`
- General host permissions for accessing website content

---

## 10. Data Sharing

Chrome Browser Lock does not sell, rent, or intentionally share user information with third parties.

The extension does not require users to create an account.

Authentication information, session information, settings, and security activity are designed to remain locally handled by the extension rather than being sent to an external Chrome Browser Lock service.

---

## 11. Data Retention and Deletion

Information is retained locally only as needed to provide the extension's functionality.

For example:

- Session information is retained while it is needed for protected-session restoration.
- Temporary recovery information is retained only for the recovery process.
- Security activity information may remain available until it is cleared by the user or removed through extension behavior.
- Authentication verification information remains until credentials are changed, reset, or the extension's data is removed.

If you uninstall Chrome Browser Lock, Chrome may remove the extension's locally stored data according to Chrome's extension-data behavior.

Files that you personally export or save, such as a recovery-key file, are separate from the extension's internal storage and remain under your control.

---

## 12. Children's Privacy

Chrome Browser Lock is not specifically directed toward children.

The extension does not intentionally collect personal information from children for advertising, profiling, or marketing purposes.

---

## 13. Security

Chrome Browser Lock is designed to protect authentication and session information using local storage and cryptographic protection.

However, no software can guarantee absolute security.

The security of the extension also depends on the security of the user's device, Chrome profile, operating system, and physical access to the computer.

Chrome Browser Lock is not designed to protect against a compromised operating system, malicious software with sufficient privileges, or a person with full administrative control of the device.
