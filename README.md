# Chrome Browser Lock

Chrome Browser Lock is a privacy-focused Chrome extension that protects your browsing session with password or PIN authentication.

It can lock your browser manually, automatically after inactivity, or when Chrome starts, while allowing your protected session to be restored after successful authentication.

## Features

- 🔐 Password and PIN authentication
- ⏱️ Automatic locking after inactivity
- 🚀 Lock protection when Chrome starts
- 🗂️ Protected session and tab restoration
- 🔑 Recovery key for forgotten credentials
- 🔒 Failed-attempt protection and temporary lockout
- 💻 Local-only data storage
- 🌐 No external servers, analytics, or telemetry

## Privacy

Chrome Browser Lock is designed with privacy in mind.

The extension does not require an account and does not send authentication credentials or browsing-session information to external servers.

Information required for authentication and session protection is handled locally on the device.

For complete information about data handling and privacy, please read:

**[Chrome Browser Lock Privacy Policy](PRIVACY.md)**

## Security

Chrome Browser Lock does not store passwords, PINs, or recovery keys as plain text.

Authentication data is protected using cryptographic hashing and securely stored locally using Chrome's storage system.

The extension is designed so that authentication and recovery operations remain local to the user's device.

## Keyboard Shortcut

**Ctrl + Shift + L** on Windows/Linux  
**Cmd + Shift + L** on macOS

Use the shortcut to lock the browser session immediately.
